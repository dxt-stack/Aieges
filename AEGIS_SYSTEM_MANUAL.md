## 2. Survival State Machine & Financial Postures

AEGIS calculates its survival state dynamically based on liquid cash reserves and net monthly burn:

$$\text{Net Burn} = \max(0, \text{Monthly Burn} - \text{Monthly Revenue})$$
$$\text{Runway (Days)} = \left(\frac{\text{Cash Reserves}}{\text{Net Burn}}\right) \times 30$$

| Survival State | Runway Window | Strategic Operational Focus | Scoring Urgency Modifier |
|---|---|---|---|
| **CRITICAL** | $< 30$ days | Immediate cash activation, emergency OPEX triage, short cash cycles ($<14$d), zero speculative capex. | **2.5x bonus** for $\le 14$d time-to-revenue; **0.25x penalty** for $>45$d. |
| **WARNING** | $30 - 90$ days | Revenue stabilization, customer retention, process optimization, fast payback acquisition. | **1.6x bonus** for $\le 30$d time-to-revenue; **0.5x penalty** for $>90$d. |
| **STABLE** | $3 - 12$ months | Balanced growth, product improvements, market penetration, organic expansion. | Baseline scoring weights ($1.0\text{x}$). |
| **STRONG** | $1 - 5$ years | Deep automation, asset diversification, infrastructure moats, strategic positioning. | Defensibility and moat bonuses prioritized. |
| **FORTRESS** | $> 5$ years (or Profitable) | Platform creation, intellectual property acquisition, multi-decade ecosystem dominance. | Maximum weight on long-term compound moats. |

## 3. Algorithmic Opportunity Scoring Model

Every opportunity is scored using multi-factor Expected Value (EV) and Risk-Adjusted Return on Effort (RAROE):

### Revenue Priority Hierarchy Weights
1. **SaaS** ($1.00$)
2. **Subscription businesses** ($0.95$)
3. **Licensing** ($0.90$)
4. **B2B services** ($0.85$)
5. **Automation services** ($0.80$)
6. **Digital products** ($0.70$)
7. **Education** ($0.65$)
8. **Marketplaces** ($0.60$)
9. **Media** ($0.50$)
10. **Advertising** ($0.40$)

### Mathematical EV Formula
$$\text{Value Numerator} = \text{Profit}_{\text{mo}} \times (0.35 S + 0.35 U + 0.15 M + 0.15 D) \times W_{\text{rev}} \times U_{\text{state}}$$
$$\text{Friction Denominator} = \left(1 + \frac{R}{10}\right) \times \left(1 + \frac{C_{\text{ops}}}{10}\right) \times \left(1 + \frac{\text{CapEx}}{5000}\right) \times \left(1 + \frac{\text{Days}}{60}\right)$$
$$\text{Expected Value (EV)} = \frac{\text{Value Numerator}}{\text{Friction Denominator}}$$

*(Where $S=$ Scalability, $U=$ Sustainability, $M=$ Moat, $D=$ Defensibility, $R=$ Risk, $C_{\text{ops}}=$ Complexity, $W_{\text{rev}}=$ Priority Weight, $U_{\text{state}}=$ Survival Bonus).*

## 4. The 6 Autonomous Organizational Divisions

1. **Research Division (`AEGIS-RESEARCH`):**
   - Market research, TAM/SAM/SOM modeling, competitor vulnerability discovery, search intent cluster scans.
2. **Product Division (`AEGIS-PRODUCT`):**
   - Autonomous MVP scoping, pricing tier calibration, value validation matrices, lean roadmaps.
3. **Engineering Division (`AEGIS-ENGINEERING`):**
   - Headless microservice architectures, zero-cleartext secret vaults, resilience audits, worker queues.
4. **Marketing Division (`AEGIS-MARKETING`):**
   - Programmatic SEO matrices (250+ targeted landing page designs), automated B2B outbound sequences.
5. **Operations Division (`AEGIS-OPERATIONS`):**
   - Standard Operating Procedure (SOP) catalogs, automated churn interception hooks, backpressure relief.
6. **Finance Division (`AEGIS-FINANCE`):**
   - Treasury stress simulation, unit economics (LTV, CAC, Payback Period), burn rate leakage audits.

## 7. Command-Line & Automation Interface

AEGIS can be operated via CLI for automation or cron jobs:

```bash
# Check organism status and telemetry
./aegis-cli.py status

# Run 3 autonomous value creation cycles
./aegis-cli.py loop --cycles 3

# List active ventures
./aegis-cli.py venture list

# Scaffold a new venture with all 16 docs
./aegis-cli.py venture new --name "AgentPulse" --category "SaaS" --mrr 25000

# Dispatch a specific task to an autonomous division
./aegis-cli.py division --name FINANCE --task run_treasury_stress_test
./aegis-cli.py division --name RESEARCH --task discover_niche_opportunities

# Update live treasury parameters
./aegis-cli.py treasury --reserves 75000 --burn 6000 --revenue 12000
```
